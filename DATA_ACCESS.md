# Data access

No raw data are redistributed in this repository. MIMIC-IV, eICU, NWICU, SICdb, and HiRID must be obtained separately under their respective access and licence conditions.

After approved access is available, configure only local paths in `config/paths.example.yaml`. Do not commit local paths, credentials, patient-level extracts, hospital identifiers, prediction files, fitted model objects, or any controlled intermediate output.

This repository provides public aggregate tables, figure inputs, specifications, and traceability records. It cannot replace source-data access or reproduce controlled patient-level calculations by itself.
