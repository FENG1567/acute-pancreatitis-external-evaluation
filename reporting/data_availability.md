# Data availability statement

Patient-level source data are not distributed with this project.

- **MIMIC-IV/MIMIC-IV-Note and eICU:** third-party credentialed/controlled-access resources. Eligible researchers must obtain access directly from the official data custodians, complete any required training or data-use agreements, and recreate local paths from the supplied example configuration. This project cannot grant access or redistribute source records.
- **HiRID, NWICU, and SICdb:** access and reuse remain governed by their respective custodians and licences. Researchers must obtain the exact versions independently. Inclusion in a local manifest does not confer redistribution rights.
- **Patient-level derived data:** cohorts, feature matrices, locked predictions, free text, identifiers, and row-level clinical-score outputs are not designated for public release. Hashes, schema, aggregate metrics, mapping rules, and audit summaries may be shared when they do not enable re-identification or reconstruct restricted records.
- **Publicly shareable materials, subject to final privacy/licence review:** analysis code, synthetic/minimal test data, variable ontology, unit/time rules, aggregate result tables, aggregate figure source data, reporting audits, and reproducibility metadata.
- **Current deposit status:** pending submission. No public repository, DOI, accession, or permanent URL has yet been verified.

Users must preserve the original database acknowledgements and citations. The release package is a research reproducibility aid; it is not a substitute for source-database access.
