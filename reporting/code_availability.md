# Code availability statement

The Stage-1 to Stage-7 analysis code, audit scripts, configuration examples, tests, environment specifications, result registry, and figure/manuscript generators are prepared for deposit after credential/privacy review and licence review.

The code is **not yet publicly deposited**. Therefore, the manuscript must not state "publicly available at" or cite a repository/DOI until an actual immutable release has been uploaded and independently opened from the cited location.

Reproduction requires independent access to each controlled source database. Example configuration files must use placeholder paths and runtime credential injection; no password, token, server account, private key, or local user path may be included. The wrappers must verify raw-file hashes and refuse to overwrite frozen model or prediction artifacts.

No software licence has been selected by the authors. A licence must be chosen before public distribution; it must be compatible with all included code and must not imply rights to redistribute third-party data.
